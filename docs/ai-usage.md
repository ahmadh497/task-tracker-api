# My Personal AI Usage Rules

## Rule 1 - What I will never paste
I will never paste passwords, API keys, access tokens, real credentials, customer data, or other private information into an AI tool.

## Rule 2 - What I will always verify before accepting
I will review the generated code and diff, make sure I understand what changed, and run the relevant tests before accepting AI-generated work.

## Rule 3 - How I will record AI contributions
I will record important AI-assisted work in the project documentation or prompt log and keep the related changes visible in Git history.
